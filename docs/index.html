InfoBuddy Calendar Sync

Keep your family’s InfoMentor school schedule in your own Google Calendar.

Quick start Privacy Policy Terms of Service

What it does

  • Reads school information from InfoMentor on the computer where you run it: tests, exams, quizzes, homework, and school events, plus the regular timetable when you opt in.
  • Creates and updates events in your own Google Calendar. There is one calendar per child for school items, named after that child. If you enable timetable sync, lessons go into a separate per-child timetable calendar that you can show or hide on its own.
  • Detects changes on later runs: events are updated in place when details change, and removed when an item has genuinely disappeared from InfoMentor, so the same item is not created twice.
  • Timetable sync uses the exact lesson scheduled for each day, not a repeating weekly rule, so substitute teachers, room changes, and other one-off adjustments are reflected accurately.

How it works

  • It is personal software you install and run on your own computer. It is not a hosted service. The author does not operate servers, does not collect data, and has no access to your information.
  • After you set it up, it can run on a schedule on your machine — for example twice a day with the included Linux timer. macOS and Windows schedulers are also included.
  • You connect Google with OAuth. On a computer with a browser, that can be a one-time sign-in window. On a headless host, you use device sign-in: open a Google URL on any other device, enter a short code, and approve access.
  • Tokens are stored in your operating system’s keychain, not in a plain text file. Each installation uses its own Google Cloud OAuth client.
  • All data stays with you: on your machine, and in your own Google account when you choose to sync.

Google access

Depending on which feature you use, the software requests only these Google permissions:

  • https://www.googleapis.com/auth/calendar — used by the InfoMentor-to-Calendar sync, so the software can create, update, and delete events in calendars in your Google account.
  • https://www.googleapis.com/auth/calendar.readonly — used to list your calendars and read events from calendars you select, for example when you link an account and choose what to keep a local copy of.
  • https://www.googleapis.com/auth/userinfo.email — used to read the email address of the Google account you linked, so the software can label and manage that account on your machine.

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. See the Privacy Policy for details.
