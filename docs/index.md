# InfoBuddy

InfoBuddy is personal software you install and run on your own computer. It is not a service. The author does not operate servers, does not collect data, and has no access to anyone's information.

The software can read school information from InfoMentor and sync it with your own Google Calendar. All data stays on your machine and in your own Google account.
